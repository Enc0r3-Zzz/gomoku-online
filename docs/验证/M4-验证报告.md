## 1. 本层交付

| 能力 | 实现 |
| --- | --- |
| ELO | 初始 1200；`E=1/(1+10^((Rb-Ra)/400))`；K=32（<30 局）/16（≥30 局）；下限 100 |
| 结算 | 胜/负/平更新评分与历史；平局双方 +0.5 期望；`ABORT` 不计分 |
| 评分流水 | `rating_history` 记录 before/after/delta |
| 结算推送 | `GAME_OVER` 增加 `deltas`、`ratings`，客户端显示「本局 ±N 分」 |
| 排行榜 | `/leaderboard` 页面 + `/api/leaderboard`，Top 50、我的排名、同分并列 |
| 重连恢复 | `STATE` 携带 `deltas`/`ratings`，断线重连也能看到本局分数变化 |

## 4. 设计说明

- 评分计算独立为 `RatingService` 接口，`EloRatingService` 可替换为 Glicko 或胜场榜（降级方案）。
- 评分与胜负场次在同一事务内更新；`users.version` 乐观锁兜底。
- 排行榜使用 `PageRequest` + `Sort(rating desc, id asc)`，同分按 id 稳定排序；名次按「严格大于我的人数 + 1」计算，天然处理并列。
- `ABORT` 只写对局结果，不写评分流水，避免双方掉线刷分。

## 5. 已知边界

- 不同 K 值下双方 delta 不一定严格互为相反数（课程项目可接受；可改为统一 K）。
- 暂无赛季/分数衰减。
- 排行榜 Top 50，未分页。
