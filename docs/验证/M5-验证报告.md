## 3. 设计说明

- 连线由服务端根据最终棋盘计算并随 `GAME_OVER`/`STATE` 下发，客户端只负责绘制，避免两端口径不一致。
- 棋盘坐标沿用 `x=列、y=行`，与数据库 `moves` 一致，回放/重连无需转换。
- 悬停预览只在 `PLAYING && 轮到我` 时启用，避免误导。
- 移动端不依赖 hover，点击仍按最近交叉点判定（`cell * 0.48` 半径）。
