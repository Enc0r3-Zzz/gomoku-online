## 2. 构建与单元测试

```bash
mvn test
```

结果：**通过**（0 失败）

覆盖：

- `PasswordEncoderTest`：BCrypt 加盐、可验证、两次哈希不同。

- `PageRenderTest`：`/login`、`/register`、`/lobby` 渲染；未登录访问大厅跳登录。
