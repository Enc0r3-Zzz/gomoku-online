| 计时 | 每步 30 秒，超时判负（已有，纳入本层回归） |
| 事务消息 | 聊天/落子/结算均在事务提交后广播 |

## 4. 设计说明

- **聊天与对局共用一条 WebSocket**，避免第二条连接的状态同步问题。
- 聊天鉴权：只有本局两名玩家可以发送；对局结束后拒绝。
- 广播采用「事务提交后」执行，测试中先收 `GAME_OVER` 再查库也能读到 `FINISHED`。
- 断线时间记录在内存房间；`GameTimeoutScheduler` 每秒扫描：
  - 当前回合超时 → 对手胜；
  - 单方掉线超时 → 对手胜；
  - 双方掉线超时 → `ABORT`。

## 5. 已知边界

- 敏感词过滤未做（可选项，报告中可作为展望）。
- 聊天历史最多返回 50 条。
- 断线判负依赖单实例内存状态，重启后进行中对局丢失。
