# 课程材料提交清单

## 1. 先填个人信息

- [ ] 报告封面：学生姓名、学号、专业、任课教师
- [ ] PPT 封面：姓名、学号、专业
- [ ] 压缩包命名：`学号_姓名.zip`

## 2. 文档检查

- [ ] 用 Word 打开 `docs/报告/Java语言及网络编程课程报告.docx`
- [ ] 检查封面、目录、分页、图表编号
- [ ] 目录页码与正文一致（目录按导出 PDF 排版生成；如 Word 因字体替换出现偏移，以正文实际页码微调）
- [ ] 导出 PDF（已提供 `Java语言及网络编程课程报告.pdf`）
- [ ] 打印版按学院要求装订

## 3. 工程材料

需要放入压缩包的内容：

```
src/                 源码
pom.xml              Maven 配置
scripts/             建库、启动、k6 脚本
skills/              gomoku-spec 规格
docs/                需求、方案、验证、AI 记录、报告
README.md            启动与部署说明
Dockerfile
docker-compose.yml
```

不要放入：

- `target/`（构建产物，可重新生成）
- `.git/`（可选，若老师要求提交 Git 历史再放）
- 任何数据库口令、token、私钥

## 4. 运行材料

- [ ] `scripts/setup-db.sql` 可在 MySQL 8 执行
- [ ] `scripts/dev.bat` 可启动（需 JDK 17）
- [ ] `mvn test` 58 个用例通过
- [ ] 可执行 jar 或 Docker Compose 可启动（二选一）

## 5. 发布与演示

- [ ] GitHub / Gitee 仓库地址（README 中填写）
- [ ] 演示视频或现场演示脚本（见 `答辩演示脚本.md`）
- [ ] PPT 与报告中的截图/数据一致

## 6. 最终自查

- [ ] 报告中的测试数量、版本号、截图与仓库一致
- [ ] 没有“待补充/TODO/占位符”残留（封面个人信息除外）
- [ ] 压缩包解压后能按 README 启动
- [ ] 已确认提交截止时间与提交方式
