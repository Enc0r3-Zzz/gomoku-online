## 5. 质量分析

- **覆盖**：核心规则与安全路径均有自动化断言；真实双客户端测试覆盖了协议、鉴权、广播、结算与数据库写入。
- **不足**：未做正式 WebSocket 压测；浏览器端交互以手工验证为主；未做敏感词/举报。
- **AI 产出质量**：样板代码与测试生成速度快；但出现过类型映射、协议认证与前端坐标三类“看起来能跑”的问题，说明测试与人工复核不可省略。
- **可复现性**：`mvn test` 一键回归；`scripts/dev.bat` 固定 JDK 17；Flyway 保证 schema 一致。

## 6. 结论

在“规格 → 生成 → 验证 → 审批 → 回归”的闭环下，AI 能显著加速工程实现，但不能替代边界定义与最终验收。本项目达到课程要求的可运行、可验证、可部署状态。
